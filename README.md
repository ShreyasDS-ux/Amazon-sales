# Amazon Sales — Exploratory Data Analysis

Exploratory data analysis and cleaning on an Amazon sales dataset, using Python.

## What's inside
- **Data cleaning:** handling missing values, standardizing data types, removing inconsistencies
- **Exploratory Data Analysis (EDA):** summary statistics to understand the shape and quality of the data
- **Visualizations:** charts built with Matplotlib/Seaborn to surface patterns in the sales data

## Tools
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## File
- `Amazon_Sales.ipynb` — full analysis notebook

## Notes
This was an early-stage EDA pass focused on getting the dataset clean and understanding its structure ahead of deeper analysis. A natural next step would be tying the EDA into specific business questions (e.g., top-performing products, regional trends).
